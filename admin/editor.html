    ¿Cómo uso el panel?

    La idea es simple: lo que ves en la miniatura es lo que se edita. Tocá cualquier texto o foto de la vista previa y cambialo ahí mismo. Nada se publica hasta que lo digas.

    Editar textos

    Tocá el texto en la vista previa (título, párrafos, botones, menú, pie) y escribí encima. Enter guarda, Esc deshace lo escrito.

    Cambiar o subir fotos

    Tocá una foto en la vista previa. Podés elegir una existente o subir una de tu PC: se optimiza sola y queda lista para la web.

    Secciones y productos

    La lista de la izquierda ordena la página: arrastrala para reordenar, el ojo la oculta, «+ Agregar sección» suma una nueva. Los productos se agregan o quitan desde el modo Textos o con la ✕ que aparece sobre el producto.

    Publicar (o no)

    Tus cambios quedan como borrador hasta «Publicar cambios» (~1 minuto en verse en la web). «Descartar» vuelve todo a lo último publicado.

    Si algo sale mal

    Las flechas ↶ ↷ (o Ctrl+Z) deshacen paso a paso. El reloj restaura versiones ya publicadas. Las copias guardan estados y las descargás a tu PC. Nada se pierde: GitHub guarda todo el historial.

    La sesión

    Ingresás con tu cuenta de GitHub y la sesión vive en esta pestaña: al cerrarla, se cierra sola. Para volver a entrar, abrí el panel y «Iniciar sesión».

    Copias de seguridad

    Copias locales del contenido (portada y datos del local), guardadas en este navegador. Antes de cada publicación se guarda una automáticamente. Restaurar carga la copia como borrador — igual que las versiones, no publica nada solo y se puede deshacer.

    Todavía no hay copias guardadas.

    Historial de versiones

    Últimas versiones publicadas de cada archivo. Al restaurar, la versión se carga como borrador para que la revises en la vista previa — nada se publica hasta que uses «Publicar cambios», y la restauración misma se puede deshacer.
